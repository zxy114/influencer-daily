2 使用技巧

Sam Altman：ChatGPT 家庭日历播客用例

@sama 👁 10M❤ 11K🔁 327 ⭐⭐⭐⭐⭐
昨晚听到一个超酷的 ChatGPT 用法：把家庭日历都连进去，再告诉它每个孩子的兴趣。每天早上开车送孩子上学时，让它生成一段播客——讲讲今天谁有足球赛、下一个孩子的生日快到了，再混点新闻。
💡 如何应用
打开 ChatGPT → Projects → 连接 Google Calendar / Outlook → 设置每日 Scheduled Task，让它在固定时间输出一段 3-5 分钟的"家庭简报"，可对接 NotebookLM 生成播客音频。

Josh Woodward：Gemini Mac 语音输入神器

@joshwoodward 👁 48K❤ 558🔁 44 ⭐⭐⭐⭐⭐

12 工作流

thenanyu：Linear 里最常见的循环 = Issue → Agent → PR → Release

@thenanyu 👁 18K❤ 127🔁 4 ⭐⭐⭐⭐⭐
Linear 里最常见的循环就是这个变体（Issue → Agent → PR → Release）。我们大概 30% 的 bug 走完了整个流程。但有几个细节——指令要明确要求 agent 深入调研根本原因…
💡 如何应用
用 Linear（或 GitHub Issues）建一个 "Issue → Codex Agent 自动开 PR → CI 通过自动 Release" 的循环。30% 的小 bug 可以无人值守掉。

14 工作流

thenanyu：用 token pledge 让 Issue 自动转 PR

@thenanyu 👁 1.5K❤ 19🔁 11 ⭐⭐⭐
你应该能为开源仓库开的 issue pledge tokens。在 issue 里写一个 spec + pledge。维护者接受后，GitHub 把 issue 原封不动交给云端 coding agent，由请求者付费。再也没有 slop PR。
💡 如何应用
等 GitHub 把 token pledge 落地之前，可以先用 "附详细 spec + 可直接执行 prompt" 的方式开 issue，提升被维护者接受/转 PR 的概率。

15 思维

zara zhang rui：你觉得稀松平常的事，对圈外人可能是全新概念

@zarazhangrui 👁 16K❤ 404🔁 26 ⭐⭐⭐⭐⭐
如果你想发文但不知道聊啥：记住你觉得"完全原生"的东西，对你圈外的人来说是全新的。做你平时的工作，然后聊聊它。别假装是别人，别过度思考。
💡 如何应用
今天的工作流、踩过的坑、调过的 prompt——直接写下来发出去。创作者最容易写的"对你没用"的内容，可能恰恰是别人最缺的。
