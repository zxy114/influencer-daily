Prompt Logs 里的"Build me an app"——LLM 编码的隐藏真相

LLM bug 类型变了

2023 年用户主动给我们 prompt logs 时被惊到——海量"build me an app for X"类请求。现在 LLMs bug 类型变了——少 off-by-one，多 system design / UI usability / 上下文缺失。

思维 Prompt
