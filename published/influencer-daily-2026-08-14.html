#3 @realmadhuguru
🧹

Prompt Debt 是新的 Tech Debt——每次模型更新要砍 50%

多数 prompts 让产品更差

Prompt debt 是新的 tech debt。每次模型更新，你应该砍掉至少 50% 的 prompts。多数 AI 产品 prompts 臃肿，让产品质量变差。典型路径：模型失败 → 加 10 条规则；tool call 失败 → 加更多上下文。

Prompt 工作流
⭐⭐⭐⭐⭐ 9/10
💡 如何应用：每个新模型版本上线时，跑一遍 prompt 库做减法——把能合并的合并，能删的删。今天就挑 5 个最臃肿的 prompt 看能不能砍掉一半。

/align-me 升级：批量提问代替来回对齐（spec decoding 同款）

批量问题能砍掉 60% 对齐税

受 @mattpocockuk 和 @trq212 启发，把 /align-me 改了一版——支持批量提问而非一问一回。同样的直觉来自 spec decoding（一次看 2-10 步），对设计任务 INCREDIBLY 有效。Theo 说 Matt 的 "grill-me" skill 是对齐 agents 的神器。

工具 教程

史上最短最强 Prompt："do smart things"——3 字管千军万马

"do smart things"

Greg Isenberg：过去 12 个月听过最牛的 agent prompt——来自一个管过数十亿 P&L、AWS 100 人团队、现在跑 34 个 agent 的人——"do smart things"（做聪明事）。

Prompt 思维
⭐⭐⭐⭐ 8/10
💡 如何应用：当 agent 卡在"该做什么"时，给它授权："do smart things, here's the goal: X"——比列 20 条规则更接近真实管理者的语言。

18 个两字 AI Prompt 套路（Allie Miller 心头好）

"now what" / "plz fix" + 16 个

"now what" —— 大项目交付后还有精力，让 AI 再给一拨；"plz fix" —— 配截图、bug 报告直接丢过去；以及另外 16 个两字 prompt。

Prompt
⭐⭐⭐⭐ 8/10
💡 如何应用：直接抄作业——把 "now what" / "plz fix" / "make it pop" / "show diff" 这种极简指令加入你的 prompt 字典，省掉 50% 的措辞纠结。
