1🎬 Prompt 模板：把任意参考图变成"手作过程"视频
Prompt ⭐⭐⭐⭐⭐
📍 @aimikoda (Kōda) 经 @Hailuo_AI 转发 · 查看原推 →
"这个 prompt 把参考图变成 15 秒的'从草稿到成品'创作过程视频。"
A cinematic creation film follows one maker reconstructing the [subject] from scratch by hand, in a single continuous shot. The piece begins as a rough sketch, then materials and tools appear one by one as the maker works—cutting, assembling, painting, finishing. The lighting shifts naturally as the scene progresses. End on a hero shot of the finished [subject] held up to camera.
如何应用
  1. 准备一张角色/产品/物品的参考图（PNG/JPG 都可）
  2. 把 [subject] 替换成具体对象（ceramic teapot / paper airplane / my profile picture）
  3. 喂给 H3 / Hailuo / Sora 等图生视频模型，duration 设为 14-15s
  4. 适合"产品幕后""手工 vlog""角色开发花絮"类短视频，B 站 / 小红书 / TikTok 通吃

3🧠 Prompt 模式：先让 AI 列假设 → 再派 N 个 agent 去验证
Prompt 工作流 ⭐⭐⭐⭐
📍 @alliekmiller · 查看原推 →
"在 Astra 里我反复用这个套路：一上来先让模型给出 N 条假设（hypotheses），然后并行派出几十到几百个 agent，每个带着不同的上下文窗口去独立研究、验证、发现。"
如何应用
  1. 研究类问题（如"竞品定价策略""用户流失归因"）一上来不要直接要答案
  2. Prompt 第一段：Before answering, list 5-10 distinct hypotheses. For each, note what evidence would confirm/refute it.
  3. 第二段再让模型分派子 agent 跑——Deep Research、Codex subagent、Claude Code Task 都支持
  4. 比单 agent 串行快 5-10 倍，且不易陷入"一个答案死磕"的陷阱

7⚙️ 技巧：动态切 effort 不断 prompt cache
技巧 ⭐⭐⭐⭐
📍 @trq212 · 查看原推 →
"动态切换 effort 不再打断 prompt cache 了，可以放心在不同环节用不同 effort。"
如何应用
  1. 之前你可能为了保 cache 死磕同一 effort → 现在可以"分类路由"：探索用 low / 终稿用 high
  2. 对长 pipeline（多步 agent、检索 + 生成）尤其有用，省 token 又省时间
  3. 实测：相同 prompt 切换 effort，单次成本可降 30-60%，质量基本不塌
8🧱 思维框架：AI 产品的 4 个槽位
思维 ⭐⭐⭐⭐
📍 @alliekmiller · 查看原推 →
"AI 的本质只需要 4 个槽位：① 一个做事的东西（Codex / Claude Code / GrokBot）② 一组工具连接（MCP、API、函数调用）③ 一个存放东西的地方（memory、向量库、文件）④ 一个分享和更新的位置（Notion / Slack / GitHub）。"
如何应用
  1. 用这个 4 槽框架给现有项目做体检——哪个槽薄弱就先补哪个，比追新模型 ROI 高得多
  2. 个人工作流同样适用：obsidian/记事本是槽 3、Slack/邮件是槽 4

12🧠 思维：注意力危机 —— Agent 让分心更严重
思维 ⭐⭐⭐
📍 @zarazhangrui · 查看原推 →
"当代最严重的危机之一是人类注意力跨度在变短。Agent 反而让事情更糟。"
如何应用

13🧭 思维：把模型选择藏到产品背后
思维 ⭐⭐⭐
📍 @realmadhuguru · 查看原推 →
"每个 AI 产品都应该把'模型选择'从用户视野里藏起来。智能只是底层引擎，用户只关心活儿干没干完。挑模型这件事对用户的认知负担太重。"

  2. 内部工具同理：给同事/客户一个统一入口，路由层自己做
