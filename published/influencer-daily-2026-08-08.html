🧠思维 / 方法论

14. 想法先说再写——录音 vs 文档

#思维 #沟通
我注意到，人们在口头说出新想法时比写文档时更清晰。在他们嘴和文档之间，核心想法会被埋掉，因为他们试图加上下文、润色、让它听起来更聪明。所以我让我团队这么做：录下来……
来源：@realmadhuguru
⭐⭐⭐⭐
如何应用：想到新点子时先录 60 秒语音（手机自带录音或 Otter），让 Whisper 转写，再用 AI 润色——比直接写文档保留更多原始洞察。

15. 与 agent 协作 = 管人

#思维 #Agent
如果你想理解真实世界中 agent 采用的动态，这篇帖子是个很好的起点。大家都太沉迷于跟聊天机器人聊天了，以至于还没有充分认识到：跟 agent 协作更像是在流程中管理一个人，而不是……
来源：@levie
⭐⭐⭐⭐
如何应用：别把 agent 当"更聪明的聊天框"——给它清晰目标、定义流程、检查产出（而不是检查过程）。心态从"提问者"切到"管理者"。
