🛠️一、工具 & 功能上新

1. Anthropic Claude Code：Session 间可互相发送消息

🛠️ 工具
"New in Claude Code: your sessions can now message each other. Instead of having to re-explain yourself in another session, you can now tell Claude to do it. It sends a summary (not your history or files), and the other session picks it up mid-task."

来源：@ClaudeDevs · 推文链接

实用性：⭐⭐⭐⭐⭐

如何应用：多 Claude 会话并行协作时不再需要手动复制粘贴上下文。让 A 会话调研、B 会话写代码，A 完成时把摘要"投递"给 B，B 直接接着干。适合长流程项目拆段：先让一个会话出方案，另一个会话基于方案立刻执行。

2. Kimi Slides：AI 一键生成可编辑 PPT（教程 #1）

🛠️ 工具 🎓 教程
"Build Slides with Kimi Work - Tutorial #1. Kimi Slides handles the entire slide-building process: - Clear structure and research, powered by Kimi K3 - Cohesive design, including polished charts and SmartArts - Editable and ready to download"

来源：@Kimi_Moonshot · 推文链接

实用性：⭐⭐⭐⭐⭐

如何应用：上传主题 + 大纲，Kimi K3 自动出调研、结构、图表、SmartArt，成品 PPT 可编辑下载。省掉"画框-排版-对图表"3 小时的死劳动。做工作汇报、产品介绍、内容选题 PPT 都能用。

3. Qwen-MM-Plugins：让 Agent Harness 真正"多模态"

🛠️ 工具
"👀 Seeing is just the beginning. With Qwen-MM-Plugins, turn your favorite agent harness multimodal-native — read images, videos & documents, edit videos, work with 3D/CAD, and more. From multimodal models → multimodal agents."

来源：@Alibaba_Qwen · GitHub

实用性：⭐⭐⭐⭐⭐

如何应用：开源插件包，把任意 agent harness 升级为多模态原生：读图、读视频、读文档，编辑视频、处理 3D/CAD。给自己的 Claude Code / Cursor / 自建 agent 接上视觉/视频能力，从纯文本 agent 一步跨到多模态 agent。

4. Gemini Notebook：统一 Prompt 栏，去掉"模式切换"

🛠️ 工具
"Notebook is built for thinking, not toggling. While others add more modes, Notebook keeps everything in a single, unified prompt bar and just does the things you want."

来源：@joshwoodward · 推文链接 · Gemini 团队产品负责人

实用性：⭐⭐⭐⭐⭐

如何应用：跟 ChatGPT 那种"模型/插件/工具"按钮堆叠不同，Notebook 只保留一个 Prompt 栏，AI 自己判断该用什么。Ultra/Pro 订阅者已经能用，下周开放给所有用户。做研究、写长文时减少决策疲劳。

5. Anthropic Claude Ultracode：动态工作流革新

🛠️ 工具
"I still think Anthropic ultracode is one of the most important coding mode innovations ever invented. If you havent understood the potential of dynamic workflows you should try to. Just met a Kill My SaaS competitor who did a pretty good submission in 3 ultracode prompts."

来源：@swyx · 推文链接 · AI Engineer Summit 创始人

实用性：⭐⭐⭐⭐

如何应用：Ultracode 模式让 Claude 不再是"单回合 prompt → 输出"，而是根据上下文动态重组工作流。已有参赛者 3 个 prompt 交出像样的 SaaS 作品。对内容创作者的启示：把"复杂任务"切成"动态工作流"而非一锅炒。

6. OpenAI GPT-Live：实时语音双向对话

🛠️ 工具
"GPT-Live can listen while it speaks. To make that feel natural at ChatGPT scale, we rebuilt the voice stack from client to model. This new architecture keeps audio flowing continuously, so deeper reasoning and tool use don't interrupt the conversation."

来源：@OpenAI · 推文链接

实用性：⭐⭐⭐⭐

如何应用：GPT-Live 在 AI 说话的同时还能继续听你说话，意味着边说边打断、补充细节成为可能。做播客采访、口述想法、随时追问的工具场景会比之前自然得多。

🎓二、教程 & 工作流

7. Linear Agent：把"Agent 做不了的事"自动变 Product Issue

⚙️ 工作流 💡 思维
"Linear Agent files feature requests for itself. If a user asks it to do something and it doesn't have the right tool, the agent reports the gap. Linear's system then adds the request to an issue so that every task the agent can't complete becomes product feedback."

来源：@petergyang · 推文链接 · Linear 团队 Nan & Jacob 访谈

实用性：⭐⭐⭐⭐⭐

如何应用：Linear 设计的反模式 → 自动化：Agent 缺什么工具 ≠ 报错，而是自动开 Issue 反馈给产品团队。抄过来用在你的内容工作流：让 AI 助手"做不了"的事自动归类到 backlog，下次升级 prompt 库时就有了真实需求数据。

8. 删掉那些"改变我人生"的 Skills（swyx 警告）

⚙️ 工作流 💡 思维
"Occasional reminder to DELETE your skills. When you are bombarded constantly by 'this skill changed my life!!' on the timeline, you will pile up stuff that at best just eats context, and at worst interacts with other skills nastily."

来源：@swyx · 推文链接 · SmolForge 博客

实用性：⭐⭐⭐⭐⭐

如何应用：你的 Claude/Cursor skill 列表是不是塞了几十个？定期做减法。Skill 多 = 占 context 窗口 = 互相干扰。一次只保留 5-10 个高频 skill，其余归档。质量比数量重要得多。

9. Codex + 视频化远程 KVM：让 Agent 看见真机屏幕

⚙️ 工作流
"I gave codex a video-enabled remote KVM so it can automate e2e test the iMessage-integration on OpenClaw. (iMessage is unreliable in VMs, and certain features such as read receipts require SIP to be disabled)"

来源：@steipete · 推文链接 · OpenClaw 创始人

实用性：⭐⭐⭐⭐

如何应用：当 Agent 需要测试"必须在真机/特定环境"才跑得动的功能时（iMessage、读回执、SIM 卡相关），给 agent 接一个视频流远程 KVM，让它能看屏幕、模拟点击。比单纯 API 自动化多覆盖一类边界场景。对自媒体运营的启发：用 AI 自动截屏验证 UI 改动。

10. 长周期 Agent 三件套：行为规范、本体论、过程监督

⚙️ 工作流 💡 思维
"How to build long-horizon AI agents: behavior specs, ontologies, process supervision - my conversation with @mitch_troy, co-founder of @trybasis"

来源：@mattturck · 推文链接 · Basis 创始人访谈

实用性：⭐⭐⭐⭐

如何应用：长周期 Agent 不是单次 prompt 能解决的。需要 (1) 行为规范（behavior specs） 明确"该不该做"，(2) 本体论（ontology） 定义领域概念关系，(3) 过程监督（process supervision） 在中间步骤给反馈而非只看结果。给自己的内容 agent 写一份"该不该发/什么时候发"的 spec。

11. 写文档 vs 录口播：说出来的想法更清晰

⚙️ 工作流 💡 思维
"Hazards of leaving voice mode on while writing. I've noticed people are much clearer when they speak through new ideas than writing a doc on it. Somewhere between their mouth and the doc, the core idea gets buried as they try to add context, polish it and make it sound smart."

来源：@danshipper · 推文链接

实用性：⭐⭐⭐⭐⭐

如何应用：把团队头脑风暴从"写文档"改成"录口播"。让 AI 先把录音转写 + 结构化整理，再产出文档。避免边写边"为了显得聪明"而稀释核心想法。适合内容创作者头脑风暴 → 脚本的工作流。

📝三、Prompt 模板

12. "defaults matter, no hedging" —— Claude.md 一句话 Prompt

📝 Prompt
"I eventually had to put 'defaults matter, no hedging' in the Claude.md file. Lesson in there somewhere!"

来源：@nikunj · 推文链接

实用性：⭐⭐⭐⭐⭐

如何应用：立刻抄进你的 Claude.md / 系统 Prompt。原意是吐槽"feature flag 太多导致默认值不准"，但这句话适用范围广得离谱——告诉 AI "别和稀泥，给默认值"，少 80% 的"取决于..."。配合"give 3 options"等结构化指令效果更佳。

13. Agent 设计黄金法则：少指令，多工具

📝 Prompt ⚙️ 工作流
"Give [your agent] as little instruction as possible. Give it the tools to load context instead."

来源：@petergyang · 推文链接 · Linear 团队

实用性：⭐⭐⭐⭐⭐

如何应用：反直觉但有效的 Prompt 设计。别在系统 Prompt 里塞规则，改成给 agent 一组"加载上下文"的工具（读文件、查 web、查数据库）。这样 Prompt 永远稳定，context 按需加载。内容工作流举例：给 AI 写作助手"读历史文章"、"读选题库"、"查 SEO 关键词"3 个工具，胜过 500 字规则。

14. 一句话 Prompt 让 Gemini Spark 每周自动生成 AI 资讯

📝 Prompt
"Every Tuesday at 12:15 PM, create a new Doc in my Drive, find the 5 biggest AI stories from that week..."（完整版见推文）

来源：@joshwoodward · 推文链接 · 引用用户 @eyishazyer

实用性：⭐⭐⭐⭐⭐

如何应用：结构化 Prompt 三件套：(1) 触发时间（每周二 12:15），(2) 产出位置（我的 Drive 新建 Doc），(3) 内容标准（当周 5 条最大 AI 故事）。丢给 Gemini Spark 定时执行。改一改就能套用：每周博客、每周竞品监控、每周内容汇总。

🎯今日趋势总结

1. Agent 基础设施成为新蓝海

Claude Code session 互通、Codex 视频 KVM、长周期 Agent 三件套（行为规范+本体论+过程监督）——单一 Agent 的时代正在过去，多 Agent 协作 + 视觉/视频接口才是下一站。

2. 删繁就简是产品主流

swyx 喊"删 skill"、Notebook 砍掉模式切换、Claude.md 一句话取代长 prompt——AI 产品迭代的主旋律是减少用户决策负担。

3. 多模态 Agent 开源化

Qwen-MM-Plugins 让任意 harness 升级多模态，Kimi Slides 端到端 PPT——创作者不再需要"文本先、视频后"的二段式工作流。
