4️⃣ Claude Code 新增 Plugin Eval：给你的 Skill/Plugin 跑体检
🛠️ 工具 💡 Prompt ⭐ 8/10
来源：@ClaudeDevs（@trq212 转推）
📝 推文原文
New in Claude Code: claude plugin eval. See what value your plugin is adding, or if it needs more work. You can create test cases, run your plugin or skill against those test cases, score those runs, then run each case again without the plugin to see the differences. We heard feedback that it's hard to know if your skills are still working with new model releases.
🇨🇳 中文翻译：Claude Code 新功能：claude plugin eval。看看你的插件/技能到底有没有价值、是不是要继续优化。你可以建测试用例，让插件或技能跑这些用例打分，然后再把插件关掉跑一遍对比差异。我们听到反馈说：新模型发布后很难判断自己写的 Skill 还好不好用。
💡 如何应用
为你的每个自定义 Claude Skill / Plugin 写 5-10 个真实测试用例（带预期输出 + 评分 prompt），每周跑一次 eval；在 Sonnet/Opus 等新模型发布时第一时间发现兼容性回归——非常适合重度依赖 Claude Code + 自定义 Skill 的开发者。
